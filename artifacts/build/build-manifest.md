| Target triple | Cross-compiler package | CI job |
|---------------|----------------------|--------|
| `x86_64-unknown-linux-gnu` | (native) | `build-x86_64` |
| `aarch64-unknown-linux-gnu` | `gcc-aarch64-linux-gnu libc6-arm64-cross` | `cross-verify` |
| `riscv64gc-unknown-linux-gnu` | `gcc-riscv64-linux-gnu libc6-riscv64-cross` | `cross-verify` |

All three targets must produce bit-identical library artifacts for the consensus crate
(`libqash_consensus.rlib`) when built with `SOURCE_DATE_EPOCH=0 CARGO_INCREMENTAL=0`.

## Non-Claims

- This is **not** a NIST / CMVP reproducible-build certification.
- The two-stage script verifies local bit-identity; independent third-party
  verification has not been performed.
- Sigstore/cosign OIDC keyless signing for release artifacts is handled by
  `.github/workflows/release.yml`; that workflow is separate from this manifest.

## Update Policy

Update this manifest after each genesis-lock candidate build:
1. Run `scripts/verify_two_stage_build.sh`.
2. Copy the new hashes from `artifacts/reproducible-build/build-hashes.txt`.
3. Update the Commit and Recorded fields above.
4. Commit with message `chore(build): update reproducible build manifest for <commit>`.
