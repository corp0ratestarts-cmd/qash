# QASH Spec Errata

Errata are normative corrections or clarifications to
`spec/pdf/QASH_Spec_v1.0.pdf`.

## Admission criteria

An erratum may be opened only when it includes:

1. A verbatim PDF quote with section and page range.
2. A concrete ambiguity, contradiction, or defect demonstrated from the quote.
3. A proposed resolution and impact statement.
4. A status: `proposed`, `accepted`, `rejected`, or `superseded`.

Engineering choices for PDF-silent areas belong in `docs/adr/`, not here.
